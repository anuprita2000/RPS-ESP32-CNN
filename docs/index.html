Rock, Paper, Scissors — camera & CNN

An ESP32-CAM streams live video over WiFi to a convolutional neural network that classifies hand gestures in real time — no cloud, no phone app, just a microcontroller and 30 lines of training code.

The model effectively behaves like a 2-class classifier: rock's blocky, high-contrast silhouette is easy to separate (91% correct), but paper and scissors both collapse toward "paper" on this low-resolution, low-contrast ESP32 feed — paper still gets picked correctly some of the time (27%), while scissors is misread as paper in every single sample tested (0/12). That's a concrete, useful failure mode: the next iteration needs either more contrastive examples of paper vs. scissors, or a preprocessing step that sharpens edges before the 32×32 downsample erases them.

The model

A small CNN, deliberately — the ESP32 can't run inference itself, so the network only needs to be light enough to train fast and generalize on a few hundred hand photos.

Running it yourself

  1. Flash MicroPython onto the ESP32-CAM, then upload the ESP32-side scripts (stream_server.py, Wifi.py, camera_test.py).

  2. Connect the board to a WiFi network using Wifi.py.

  3. Run stream_server.py on the ESP32 to start streaming frames.

  4. On the laptop, run classify_stream.py — it connects to the ESP32's IP, receives frames, and classifies each one live.
